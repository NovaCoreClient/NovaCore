🌌 NovaCore Launcher

NovaCore is not just another Minecraft launcher; it is a meticulously engineered, premium client designed to offer a cinematic, highly responsive user experience. Featuring volumetric glassmorphism UI, seamless Microsoft authentication, and a built-in 3D skin engine, NovaCore redefines how players interact with their game instances.

✨ Key Features

**🎨 AAA Premium Interface:** A stunning cinematic boot sequence, volumetric glassmorphism panels, and buttery-smooth micro-interactions. Includes a breathing launch button and dynamic background ambiances.

**🔐 Smart Authentication:** Dual-system login supporting both secure Microsoft/Xbox Live accounts (via `msmc`) and legacy Offline Profiles, complete with a fast account-switcher.

**⚡ Intelligent Instance Engine:** Automatically detects and allocates the correct Java environment (Java 8 for legacy, Java 21+ for modern). Supports native Forge and Fabric injection.

**📦 Built-in Mod Manager:** Easily toggle local `.jar` mods on and off without deleting them. Automatically fetches missing essential dependencies (like Fabric API, Sodium, and Iris) directly from Modrinth.

**👕 3D Skin & Profile Engine:** Import, manage, and preview your skins with a custom-built, pure-CSS rotating 3D character model. Automatically injects local skins into the game via `CustomSkinLoader`.

**📡 Live Multiplayer Dashboard:** Native server pinging engine that displays live MOTDs, latency (ms), player counts, and server icons without needing to launch the game.

**🔄 Over-The-Air (OTA) Updates:** Built-in auto-updater that silently pulls and installs the latest patches directly from GitHub Releases.

**📊 Session Analytics:** Tracks and saves your total playtime hours and active profiles directly to your local drive.
